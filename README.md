# Mortal MJ

FFXIV 国服「多玛方城战」麻将 AI 辅助插件，基于 Mortal 麻将 AI 提供实时打牌建议与自动化操作。

## 功能

- 🀄 实时打牌建议（Mortal AI，含向听数）
- 🤖 自动出牌（随机延迟，拟人化）
- 🍥 自动吃 / 碰 / 杠 / 荣和（含多种吃法精确匹配）
- 👀 看整桌：实时显示别家打出的牌
- 💡 吃 / 碰 / 杠 / 立直 / 和 / 放弃建议

## 下载与安装

1. 下载本仓库根目录的 4 个文件：
   - `MortalMJPlugin.dll`
   - `MortalMJPlugin.pdb`
   - `MortalMJPlugin.json`
   - `MortalMJPlugin.deps.json`
2. 把这 4 个文件一起放入卫月（Dalamud）插件目录（例如 `MJ\`）。
3. 游戏内输入 `/mjui` 打开设置窗口，填「Mortal 根目录」。
4. 进入多玛方城战即可使用。

## 依赖（重要）

本插件需要一套可用的 Mortal AI 环境（Python 3.14 + torch + libriichi + 模型权重）。

- **整合包（推荐）**：见发布说明，解压后双击「修复路径.bat」，再在 `/mjui` 里填解压目录。
- 或自行准备 Mortal 环境后填路径。

## 命令

| 命令 | 作用 |
|---|---|
| `/mjui` | 打开设置窗口 |
| `/mjauto` | 开关自动出牌 |
