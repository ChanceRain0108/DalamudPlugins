# Mortal MJ

FFXIV 国服「多玛方城战」麻将 AI 辅助插件，基于 Mortal 麻将 AI 提供实时打牌建议与自动化操作。

本插件参考FFXIV-AutoMahjongSolver源码所作。可基于牌河以及手牌给出最优解（或许？）。

## 功能

- 打牌建议（Mortal AI，含向听数）
- 自动出牌
- 自动吃 / 碰 / 杠 / 和
- 实时显示别家牌
- 吃 / 碰 / 杠 / 立直 / 和 / 放弃建议

## 下载与安装

1. 下载仓库根目录文件
2. 把文件一起放入Dalamud插件目录
3. 输入/mju 打开设置窗口
4. 进入多玛方城战即可使用

## 依赖

插件需要 Mortal AI 环境（Python 3.14 + torch + libriichi + 模型权重）。

## 命令

| 命令 | 作用 |
|---|---|
| `/mjui` | 打开设置窗口 |
| `/mjauto` | 开关自动出牌 |
