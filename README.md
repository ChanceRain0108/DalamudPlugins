# Mortal MJ

FFXIV 国服「多玛方城战」麻将 AI 辅助插件，基于 Mortal 麻将 AI 提供实时打牌建议与自动化操作。

本插件参考 FFXIV-AutoMahjongSolver 源码所作，可基于牌河以及手牌给出最优解。


## 功能

-  实时打牌建议
-  自动出牌
-  自动吃 / 碰 / 杠 
-  自动立直
-  自动和牌
-  看整桌：实时显示别家打出的牌
-  吃 / 碰 / 杠 / 立直 / 和 / 放弃建议

## 下载与安装

1. 打开游戏内卫月（Dalamud）插件安装器，添加插件仓库链接：

   ```
   https://raw.githubusercontent.com/ChanceRain0108/DalamudPlugins/main/pluginmaster.json
   ```

2. 在安装器里搜索Mortal MJ
3. 启动插件，若环境未就绪会自动弹出「环境引导」窗口
4. 「下载环境（约 300MB）」→ 自动解压并配置 → 自动重启 Mortal
5. 进入多玛方城战

## 命令

| 命令 | 作用 |
|---|---|
| `/mjui` | 打开功能开关设置窗口 |
| `/mjsetup` | 打开环境引导窗口（下载环境 / 重新检测） |
| `/mjauto` | 开关自动出牌 |

## 依赖

本插件需要一套可用的 Mortal AI 环境（内置 Python + torch + libriichi + 模型权重）。

- 推荐直接用插件内的「下载环境」按钮自动获取，无需手动配置。
- 若网络较慢或下载失败。
